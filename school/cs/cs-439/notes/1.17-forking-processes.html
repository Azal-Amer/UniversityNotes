The Big One: Form

The first process was made by kernel_main. How does main make a new process?

The way you make a new process in Unix systems is a system call called fork(). It takes no argumjents. That new process which is produced is an identical copy of the one which created it. Fork as in a fork in the road. When a process calls fork, a nearly identical twin is created.
Each time children in forked processes are created, the children's ID are distinct from the parent and all else in the tree.

In general all of our system calls return an integer representation, where an error is indicated by returning a negative value. fork() return an id.
